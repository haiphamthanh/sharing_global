Để kiểm tra **từng loại thay đổi ảnh hưởng đến dự án** sau mỗi lần Apple phát hành **Xcode mới hoặc framework mới**, bạn cần dựa vào các **tài liệu chính thống** sau, tương ứng với **loại thay đổi** cụ thể. Dưới đây là bảng tra cứu toàn diện:

## ✅ BẢNG TÀI LIỆU KIỂM TRA THEO LOẠI THAY ĐỔI

| 🧩 **Loại thay đổi**                               | 📄 **Tài liệu kiểm tra**                                                                                                                                                                        | 🔍 **Cách dùng**                                                                                      |
| ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| 🟢 **API mới thêm**                                | [API Changes – Diff Viewer](https://developer.apple.com/documentation/)                                                                                                                        | Chọn framework → tab **"Changes"** để xem các API mới, cập nhật                                      |
| 🟡 **API bị deprecate**                            | [Xcode Release Notes](https://developer.apple.com/documentation/xcode-release-notes) <br> [iOS/iPadOS/macOS Release Notes](https://developer.apple.com/documentation/ios-ipados-release-notes) | Tìm từ khóa **"Deprecated"**, "No longer recommended", "Will be removed"                             |
| 🔴 **API bị xoá hoặc hành vi thay đổi**            | Như trên + [WWDC Videos – What's New](https://developer.apple.com/videos/)                                                                                                                     | Xem các đoạn "Behavior Changes", "Breaking Changes", ví dụ: `viewDidLoad behavior changed in iOS 17` |
| 🟠 **Thay đổi về quyền riêng tư và Info.plist**    | [App Privacy Requirements](https://developer.apple.com/app-store/app-privacy-details/) <br> [App Store Review Guidelines](https://developer.apple.com/app-store/review/guidelines/)            | Xem phần yêu cầu các trường mới trong `Info.plist`, thường có ví dụ rõ                               |
| ⚠️ **Thay đổi toolchain, compiler, Swift version** | [Swift Language Updates](https://swift.org/blog/) <br> [Swift Evolution Proposals](https://github.com/apple/swift-evolution)                                                                   | Dò các thay đổi ngôn ngữ: closure syntax, access control, type inference...                          |
| 🧪 **Test & Debug Crash**                          | [Instruments Documentation](https://developer.apple.com/documentation/instruments) <br> [XCTest Documentation](https://developer.apple.com/documentation/xctest)                               | Dùng `Instruments` để kiểm tra memory, thread, crash; `XCTest` để validate logic                     |
| 🧱 **Giao diện UI mới / thiết bị mới**             | [Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/)                                                                                                   | Kiểm tra app có hiển thị tốt trên thiết bị mới, hỗ trợ layout mới không                              |
| 🔐 **Các API cần quyền truy cập mới**              | [Privacy Manifest Documentation](https://developer.apple.com/documentation/bundleresources/privacy_manifest)                                                                                   | Từ iOS 17+ bạn cần khai báo API nhạy cảm trong Privacy Manifest                                      |

## 📌 CÁCH KẾT HỢP TRA CỨU

Giả sử bạn thấy trong **Xcode 16 Release Notes** có dòng:

> “`UIApplication.shared.delegate` access from background threads now throws runtime exception.”

👉 Bạn nên:

1. Tìm chi tiết hơn tại [Xcode Release Notes](https://developer.apple.com/documentation/xcode-release-notes)
2. Dò trong [UIKit API Changes](https://developer.apple.com/documentation/uikit)
3. Xem WWDC video hoặc doc về "Concurrency and UIKit"
4. Kiểm tra project xem có chỗ nào gọi delegate ở thread phụ → sửa thành main thread
