## ✅ BƯỚC 2: SO SÁNH VỚI DỰ ÁN HIỆN TẠI

Dùng các công cụ sau để rà soát nhanh:

### 1. **Tìm Deprecated API**

* Xcode sẽ gợi ý các API không còn được khuyến khích dùng (gắn tag `@available(*, deprecated)`).
* Mở tab **Issue Navigator (⌘ + 8)** → chọn loại **Deprecations and Warnings**.
* Với Swift: dùng lệnh sau để rà API bị deprecated:

```bash
grep -r "deprecated" ./YourProjectFolder
```

### 2. **Dò từ khóa thay đổi liên quan trong Release Notes**

Tìm theo các từ khóa framework bạn đang dùng:

* Ví dụ: `UIKit`, `SwiftUI`, `Combine`, `CoreData`, `AVFoundation`, `StoreKit`, `WidgetKit`, `MapKit`, v.v.
* Dùng `Cmd + F` trong release notes để dò.

### 3. **So sánh SDK Version / Toolchain**

* Kiểm tra nếu dự án đang dùng SDK/iOS version cũ hơn bản Xcode mới hỗ trợ.
* Xem lại `Deployment Target` và `Base SDK` trong `.xcodeproj`.

## ✅ BƯỚC 3: PHÂN LOẠI ẢNH HƯỞNG VÀ HÀNH ĐỘNG

| Loại thay đổi                                 | Mức độ ảnh hưởng                | Hành động                                      |
| --------------------------------------------- | ------------------------------- | ---------------------------------------------- |
| 🟢 Thêm API mới                                | Không ảnh hưởng trực tiếp       | Ghi chú để tận dụng sau                        |
| 🟡 API cũ bị deprecated                        | Có thể warning, nhưng vẫn chạy  | Tìm thay thế tương đương                       |
| 🔴 API bị removed / behavior thay đổi          | Có thể crash hoặc sai logic     | Refactor gấp                                   |
| 🟠 Thay đổi về quyền riêng tư / Info.plist     | Ảnh hưởng khi submit App Store  | Cập nhật file `Info.plist` và mô tả permission |
| ⚠️ Thay đổi toolchain, compiler, Swift version | Gây lỗi build / logic khác biệt | Kiểm tra lại toàn bộ build, test logic         |

## ✅ GỢI Ý QUY TRÌNH TỰ ĐỘNG (CI/CD)

1. Thiết lập job CI chạy với Xcode bản mới nhất (GitHub Actions / Bitrise).
2. Mỗi khi Apple phát hành Xcode mới, trigger pipeline test lại toàn bộ.
3. Export report nếu có deprecated API hoặc crash.
4. Có thể tích hợp `danger-swift` để tự động báo lỗi deprecated trong PR.
