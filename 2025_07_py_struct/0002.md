Đây là một **vấn đề rất hay gặp khi dự án Python module hóa**:

* Làm sao để **lưu file local (kết quả, logs, model, dữ liệu,...)**
* Mà **không bị lỗi đường dẫn** dù chạy trên máy ai, hoặc chạy từ main hay từ các module con?

---

## **1. Nguyên nhân lỗi đường dẫn**

* Khi dùng `open('output/result.txt', 'w')`, đường dẫn **tương đối** (relative) sẽ phụ thuộc vào **working directory** lúc chạy.
* Nếu chạy từ root (`python main.py`): OK
  Nếu chạy từ module con, hoặc IDE đặt working dir khác: **Lỗi** — file không được tạo đúng chỗ hoặc bị "lạc" ở nơi khác.

---

## **2. Giải pháp Chuẩn: Luôn xác định đường dẫn dựa trên vị trí file gốc (project root)**

**Cách tốt nhất:**

* **Lấy đường dẫn tuyệt đối của project root** (hoặc thư mục cha mong muốn)
* Các module đều build path dựa trên đó (không bao giờ dùng relative path "mù mờ")

---

### **Ví dụ thực tế: Tạo và quản lý đường dẫn lưu file**

#### **Bước 1: Xác định Project Root**

Trong `main.py` (hoặc file config chung):

```python
import os

# Đường dẫn tuyệt đối tới thư mục gốc dự án
PROJECT_ROOT = os.path.dirname(os.path.abspath(__file__))

# VD: Thư mục lưu kết quả
OUTPUT_DIR = os.path.join(PROJECT_ROOT, "output")
if not os.path.exists(OUTPUT_DIR):
    os.makedirs(OUTPUT_DIR)
```

#### **Bước 2: Các module đều dùng PROJECT\_ROOT hoặc OUTPUT\_DIR**

**src/module\_a/func\_a.py**

```python
import os
from main import OUTPUT_DIR  # hoặc import từ 1 file config chung

def save_result(filename, data):
    file_path = os.path.join(OUTPUT_DIR, filename)
    with open(file_path, "w") as f:
        f.write(data)
```

#### **Hoặc: Đặt file config chung cho path**

Tạo `src/config.py`:

```python
import os

PROJECT_ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
OUTPUT_DIR = os.path.join(PROJECT_ROOT, "output")
if not os.path.exists(OUTPUT_DIR):
    os.makedirs(OUTPUT_DIR)
```

Các module chỉ cần:

```python
from src.config import OUTPUT_DIR
```

#### **Bước 3: Khi lưu file, luôn dùng OUTPUT\_DIR**

```python
with open(os.path.join(OUTPUT_DIR, 'result.txt'), 'w') as f:
    f.write('Hello!')
```

---

## **3. Bonus: Xử lý path tương thích mọi OS**

Nên luôn dùng `os.path.join`, tránh nối chuỗi path kiểu thủ công (`'output/' + filename`).

---

## **4. Tránh tuyệt đối:**

* Không hard-code path tuyệt đối hoặc path tương đối tính từ module con!
* Không lưu ở thư mục "ảo" khi test hoặc debug, vì file sẽ bị lạc chỗ.

---

## **5. Có thể nâng cao: Sử dụng pathlib**

Từ Python 3.6+ dùng rất tiện:

```python
from pathlib import Path

PROJECT_ROOT = Path(__file__).parent.resolve()
OUTPUT_DIR = PROJECT_ROOT / 'output'
OUTPUT_DIR.mkdir(exist_ok=True)

with open(OUTPUT_DIR / 'result.txt', 'w') as f:
    f.write('Hello pathlib!')
```

---

## **6. Tổng kết**

* **Định nghĩa PROJECT\_ROOT một chỗ duy nhất (main/config)**
* **Các module import path từ đó, không tự động phát sinh path**
* **Tạo thư mục nếu chưa có trước khi lưu**
* **Dùng os.path.join hoặc pathlib cho an toàn**
