Khi Apple phát hành một bản **Xcode mới** và các **framework mới** (thường đi kèm với các phiên bản iOS/macOS mới), các nhà phát triển cần thực hiện kiểm tra nhiều khía cạnh để đảm bảo ứng dụng vẫn hoạt động ổn định, tương thích và tận dụng các tính năng mới. Dưới đây là danh sách các việc cần làm và các nguồn tài liệu kiểm tra liên quan:

---

## ✅ CÁC VIỆC CẦN KIỂM TRA

### 1. **Kiểm tra tương thích hệ điều hành mới**

* Chạy app trên simulator/device với OS mới để kiểm tra crash, lỗi UI, hiệu năng.
* Đảm bảo backward compatibility với các OS cũ mà bạn còn hỗ trợ.

### 2. **Build lại ứng dụng với Xcode mới**

* Sửa các lỗi build (nếu có).
* Kiểm tra cảnh báo mới (warnings) và deprecated API (API bị loại bỏ).

### 3. **Kiểm tra thay đổi API và framework**

* Các framework như SwiftUI, UIKit, Combine, CoreML… có thể thay đổi hành vi hoặc bị cập nhật.
* Đọc Release Notes để nắm các thay đổi chính thức.

### 4. **Cập nhật SDK version (Deployment Target)**

* Xem xét nâng minimum deployment target (nếu phù hợp).
* Kiểm tra tính tương thích và cấu hình `Info.plist`.

### 5. **Kiểm tra thay đổi về quyền riêng tư và bảo mật**

* Apple thường thêm các permission mới hoặc thay đổi cách hiển thị cảnh báo với người dùng (ví dụ: `NSPrivacyAccessedAPIs`, `NSLocationWhenInUseUsageDescription`...).

### 6. **UI/UX và thiết bị mới**

* Kiểm tra app trên các thiết bị/simulator mới được Apple giới thiệu (iPhone mới, iPad, Vision Pro...).
* Đảm bảo app hiển thị tốt trên các kích thước màn hình và tỉ lệ khác nhau.

### 7. **Kiểm tra Performance & Battery Impact**

* Dùng Instruments (trong Xcode) để test performance, memory leak, CPU usage.
* Test launch time vì Apple thường khắt khe hơn với thời gian khởi động app.

### 8. **Review App Store Submission Requirements**

* Xem lại quy định mới từ App Store Review Guidelines.

## ✅ GỢI Ý QUY TRÌNH LÀM VIỆC

1. **Cài bản Xcode mới (có thể để bản cũ song song).**
2. **Clone branch riêng để thử build bằng Xcode mới.**
3. **Chạy test tự động (unit test, UI test).**
4. **Build thử app lên thiết bị/simulator chạy iOS mới nhất.**
5. **Ghi nhận thay đổi về behavior, log warning, API lỗi thời.**
6. **Cập nhật tài liệu kỹ thuật nội bộ nếu có framework hoặc API mới cần áp dụng.**
